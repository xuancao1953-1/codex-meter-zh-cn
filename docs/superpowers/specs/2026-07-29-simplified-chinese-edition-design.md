# Codex Meter 简体中文独立版设计

## 1. 项目背景

本项目基于 [TheJhyeFactor/codex-meter](https://github.com/TheJhyeFactor/codex-meter)
的 `v1.5.0` 版本和提交 `75e3a1e8c4284afc842fb6d4910a4d8127fe203c`
制作。原项目采用 MIT License，中文版必须保留原始 `LICENSE`、原作者版权声明、
提交历史和上游链接。

中文版是独立的社区派生版本，不代表原作者，也不隶属于、未获 OpenAI 赞助或背书。

## 2. 目标

- 提供一个可独立安装的 `Codex Meter 中文版.app`。
- 固定使用简体中文，不依赖 macOS 当前系统语言，也不提供语言切换开关。
- 完整翻译用户能看到或听到的界面文字，同时保持额度读取、账户切换、本地活动统计和
  API 标准价格估算等原有功能不变。
- 允许英文原版和中文版同时安装，且中文版的偏好设置与登录启动项不覆盖原版。
- 通过公开 GitHub 仓库发布源码，并由 GitHub Actions 在 macOS 环境完成测试、通用
  二进制构建和 ZIP 打包。

## 3. 非目标

- 不修改或替换用户已安装的英文原版。
- 不加入中英文切换、自动更新器、新的数据源或新的额度计算逻辑。
- 不读取、复制或上传 `~/.codex/auth.json`、密码、MFA 信息、提示词或回复内容。
- 不声称中文版经过 Apple 公证，也不声称它是原作者或 OpenAI 的官方版本。
- 首个中文版不自动迁移英文原版保存的额外账户和界面设置。

## 4. 产品身份与共存规则

| 项目 | 中文版设计 |
| --- | --- |
| App 文件名 | `Codex Meter 中文版.app` |
| 菜单和窗口名称 | `Codex Meter 中文版` |
| Bundle Identifier | `com.xuancao1953.codexmeter.zhcn` |
| 最低系统版本 | macOS 13 Ventura |
| 支持架构 | Apple silicon `arm64`、Intel `x86_64` |
| 界面语言 | 固定 `zh-Hans` |
| 签名方式 | Ad-hoc 签名，不进行 Apple 公证 |
| 首个版本号 | `1.5.0-zh.1` |

独立 Bundle Identifier 会让 `UserDefaults` 和“登录时打开”注册项与英文原版分开。
中文版继续使用 Codex 的标准本地配置路径，因此默认 Codex 账户无需重新提供凭据；
英文原版中手动添加的额外账户不会自动复制，用户可在中文版中重新添加。

英文原版和中文版可以同时安装，但文档应建议只运行其中一个，以避免菜单栏重复图标、
重复轮询和重复低额度通知。用户可保留英文原版作为回退版本，并只为中文版启用
“登录时打开”。

## 5. 本地化架构

### 5.1 中文资源

新增 `Resources/zh-Hans.lproj/Localizable.strings`，集中保存简体中文文案。新增
`Sources/CodexMeter/L10n.swift`，提供固定加载 `zh-Hans` 资源和格式化占位符的接口。
调用方显式使用 `L10n`，不依赖 SwiftUI 对字符串字面量的隐式本地化行为。

当资源文件意外缺失时，`L10n` 中的中文默认值仍应返回可读中文，不回退成散落的英文
界面。

### 5.2 翻译范围

以下用户可见文字必须全部迁移到 `L10n`：

- 菜单栏右键菜单、工具提示和辅助功能描述。
- 弹出面板中的额度窗口、重置时间、账户、本地活动、成本估算和设置。
- 刷新、登录、切换、删除账户时的状态、按钮、确认框和错误提示。
- 低额度、重置、节省金额和 Token 里程碑通知。
- 预览窗口标题、空状态、过期状态和不可用状态。
- 显示模式、货币、通知阈值及“登录时打开”等设置项。

`Codex`、`OpenAI`、模型 ID、货币代码（USD、AUD、EUR）和系统路径保持原样。
面向 AI 用户的 `Token` 一词保留英文，必要时在首次出现处写作“Token（令牌）”。
“API-equivalent estimate”统一翻译为“按 API 标准价格估算”，不得描述为 ChatGPT
订阅账单。

## 6. 构建与发布

`scripts/build-app.sh` 应：

1. 分别构建 `arm64-apple-macosx13.0` 和 `x86_64-apple-macosx13.0`。
2. 用 `lipo` 合并通用二进制。
3. 创建 `Codex Meter 中文版.app`，复制 `Info.plist` 和 `zh-Hans.lproj`。
4. 对 App 执行 ad-hoc 签名并严格验证签名。
5. 输出仅包含独立中文版 App 的 `Codex-Meter-ZH-CN-1.5.0-zh.1.zip`。

GitHub Actions 包含两条路径：

- 分支或 Pull Request：在 macOS runner 上运行非实时测试、源码本地化审计和 App
  构建验证。
- 推送 `v*-zh.*` 标签：重复完整验证，生成 ZIP 和 SHA-256 校验文件，并创建公开
  GitHub Release。

由于版本未经过 Apple 公证，README 必须说明首次启动时可在 Finder 中按住 Control
点击 App，选择“打开”并再次确认。

## 8. 错误处理与隐私

所有原有的诚实错误状态保持不变：额度读取失败时显示“不可用”或“数据已过期”，不展示
看似最新的旧百分比，也不编造重置时间。

本地化层仅负责文案，不改变账户或日志数据流。错误详情可以包含系统返回的技术信息，
但前缀、操作建议和确认按钮必须为中文。项目继续遵守原版隐私边界：不引入分析、广告、
跟踪、外部数据库或额外网络服务。

## 9. 测试与验收

### 9.1 自动检查

- 原项目的解析器、活动统计、账户存储和 CLI 测试在 macOS runner 上通过。
- 新增本地化审计，验证所有已登记的文案键存在、格式化占位符一致，并对 App 源码中的
  用户可见英文字符串执行允许名单检查。
- 验证 App 的 `CFBundleDisplayName`、Bundle Identifier、版本、最低系统版本和固定
  中文本地化声明。
- 验证 App 包含 `zh-Hans.lproj/Localizable.strings`。
- 验证最终二进制同时包含 `arm64` 和 `x86_64`，且 `codesign --verify --deep --strict`
  成功。
- 验证 ZIP 仅包含 `Codex Meter 中文版.app`，并生成对应 SHA-256。

### 9.2 macOS 功能验收

- 启动后菜单栏只出现中文版名称和中文提示。
- 默认 Codex 账户可读取额度，失败时显示中文且不伪造数据。
- 面板、设置、账户操作、通知、右键菜单和辅助功能描述无遗漏英文；允许名单中的专有
  名词除外。
- “登录时打开”只控制中文版。
- 英文原版仍可安装和运行，文件及设置不被中文版覆盖。
- 退出并重启中文版后，中文版设置能独立保留。

## 10. 更新策略

首版不包含自动更新器。英文原版即使更新，也不会覆盖独立中文版。若 Codex
app-server 接口或本地日志格式发生变化，中文版需要从上游合并兼容性修复，重新运行
本地化审计，并发布新的 `-zh.N` 版本。
